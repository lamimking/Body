BodyStealBody  -  Bodysteal PLUGIN BY L4M1MK1NG

Build:
  1. Copy your BetterModel jar to  libs/BetterModel.jar
  2. mvn package          (jar appears in target/)
  3. Put the jar in the server's plugins folder, next to BodySteal and BetterModel.
     BodySteal must be built from the newest source (it needs getLostParts/getHeldParts/isCaged).
  4. Start the server, then run /bm reload ONCE so BetterModel loads the body models.
