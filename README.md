# BodySteal

Bodysteal PLUGIN BY L4M1MK1NG

Lose body parts when you die. Lose them all and get caged.

## Plugins
- BodySteal: the main plugin (parts, saw menu, cage)
- BodyStealBody: custom body that hides lost limbs and shows stolen parts with the owner's skin (needs BetterModel)

## Install
1. Download the jars from the Actions tab, under Artifacts.
2. Put BodySteal, BodyStealBody and BetterModel in the server's plugins folder.
3. Start the server, then run /bm reload once.

## Requirements
- Paper 1.21.11
- Java 21
- BetterModel (MIT license)
